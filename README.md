
# WireFrame de Controle de Pessoas

Projeto de gerenciamento de pessoas que permite cadastrar, listar, buscar, editar e excluir registros de forma prática e intuitiva.

## Funcionalidades

- Cadastrar nova pessoa
- Listar todas as pessoas
- Buscar pessoa por CPF
- Editar registros existentes
- Excluir registros
- Navegação fácil com botões de voltar e nova busca
- Interface responsiva e clean

## Rodando localmente

Clone o projeto

```bash
  git clone https://github.com/Gabe12-dev/wireframe-pessoa
```

Entre no diretório do projeto

```bash
  cd wireframe-pessoa
```

Instale as dependências

```bash
  npm install
```

Inicie o servidor

```bash
  npm run start
```
